# 发布前必须复核 OpenSky 数据条款

这些快照已下载到本地，用于教师要求的 OpenSky 兼容性试验。由于本次自动访问 OpenSky 数据条款页面被站点策略阻止，当前工作不对公开再分发权限作推断。

将本目录推送到公开或共享仓库前，负责 OpenSky 数据的助教必须：

1. 打开 <https://opensky-network.org/data/data-terms> 阅读当时有效的完整条款；
2. 确认课程使用、快照再分发和派生文件发布均被允许；
3. 按条款补充准确署名、引用或访问限制；
4. 若条款不允许随实践包分发，删除 `source/` 及派生数据，只保留下载脚本和本地生成说明。

在完成上述人工复核前，不应把本目录合并到远端 `main`。
