# M1 内部正确流程参考

`OpenSky离线状态数组 -> 发送方字段解析/必需与可空检查 -> 来源派生字段 -> 41字节TeachingLink封装 -> 模拟传输 -> 接收方长度/头字段/checksum/保留位/标志一致性检查 -> 物理量和空值恢复 -> CSV/SQLite（选做） -> 单源多时刻航迹与当前态势 -> 双格式候选映射 -> 人工核验后的统一消息 -> 固定一致性规则 -> 告警与质量态势 -> M6展示`

内部验收要点：

- 外部接口、发送方内部状态、线上帧和接收方内部记录是四个不同层次。
- `message_valid`、字段有效性和业务质量不得混用。
- TeachingLink 不对应真实装备或行业协议，简单加和校验不是 CRC 或安全认证。
